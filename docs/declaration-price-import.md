# Перечень цен для расчёта по декларации

`bot/src/declaration-price-list.js` формируется из предоставленного владельцем PDF ФТС.
Текущий источник содержит 158 страниц и 8334 последовательно пронумерованные строки.
SHA-256 источника, число страниц и строк записаны в `DECLARATION_PRICE_SOURCE`.

Для обновления требуется Python с `pdfplumber`:

```sh
python3 scripts/import-declaration-prices.py SOURCE.pdf
node bot/test/declaration-flow.test.mjs
```

Импорт использует границы трёх столбцов: номер, наименование, цена. Числа в конце
модели не переносятся в стоимость. Проверяются последовательность номеров,
наличие таблицы на каждой странице и положительные цены с двумя десятичными знаками.
Файл заменяется только после успешной проверки всего документа.

Все исходные строки сохраняются, включая одинаковые названия с разными ценами.
При нескольких совпадениях бот предлагает выбор, а не назначает первую цену.
Поиск принимает различия регистра и пробелов (`RAV4` / `RAV 4`), сохраняет
слова комплектаций и знак `+`. В результат подставляется исходное наименование
из перечня. Уточнение текстом после списка вариантов остаётся в сценарии декларации.
