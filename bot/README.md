# Telegram-бот «Брокер ГРАНИ»

Cloudflare Worker принимает webhook Telegram и показывает меню прямо в чате.

Бот принимает текстовый запрос с маркой, моделью и годом (например, `Kia Niro EV 2022`), ищет автомобиль в том же автоматически обновляемом справочнике, предлагает выбрать модификацию и рассчитывает утильсбор прямо в переписке.\n\nБот также принимает пересланные или загруженные PDF-файлы СБКТС и выписки ЭПТС. Он распознаёт характеристики автомобиля, рассчитывает утильсбор и:

- для СБКТС сразу определяет срок уплаты и пени;
- для выписки ЭПТС просит пользователя ответом указать дату оформления СБКТС;
- после расчёта предлагает указать будущую дату подачи документов для точного пересчёта пеней.

Последние 10 завершённых расчётов сохраняются в разделе «Мои заявки» мини-приложения. Архив общий для расчётов из бота и мини-приложения, привязан к Telegram-пользователю и хранится во встроенном Durable Object Cloudflare. В разделе есть кнопка полной очистки.

Файлы обрабатываются в памяти Cloudflare Worker и нигде не сохраняются. Максимальный размер PDF, который бот может получить через Telegram, — 20 МБ.

При изменении `tabs/utilsbor/rates.xlsx` обновите встроенные в Worker ставки командой `npm run export:bot-rates`.

## Настройки Cloudflare

Cloudflare автоматически обнаруживает конфигурацию в корне репозитория.

Runtime secrets:

- `BOT_TOKEN` — токен из BotFather;
- `WEBHOOK_SECRET` — случайная строка для проверки запросов Telegram;
- `SETUP_KEY` — временная случайная строка для запуска настройки webhook;
- `DONATE_CARD` — номер карты, который бот показывает в разделе поддержки.
- `AVC_TOKEN` — API-токен AvtoVinCod, только секрет Cloudflare Worker.
  Метод `customs-fts` должен быть подключён в кабинете провайдера.

Runtime variables:

- `CONTACT_URL` — публичная ссылка менеджера, например `https://t.me/username`;
- `DONATE_URL` — публичная ссылка для поддержки проекта.

После первого развёртывания откройте:

`https://<worker>.workers.dev/setup/<SETUP_KEY>`

После успешного ответа `ok: true` удалите секрет `SETUP_KEY` в Cloudflare.

## Персональная сверка с ФТС

После распознавания СБКТС/ЭПТС в личном чате появляется отдельная кнопка
«Проверить ФТС». По умолчанию доступ есть только у администратора; выдача
и отзыв — `/admin` → «Пользователи» → карточка → «Включить/отключить проверку ФТС».
Доступ независим от проверки подписи и хранится в D1 (`fts_access` создаётся
автоматически). При недоступной базе доступ закрыт. Без `AVC_TOKEN` кнопка скрыта.

Запрос выполняется только по нажатию, отправляется один распознанный
идентификатор, PDF и фамилия провайдеру не передаются. Если корректный VIN
не распознан и отдельного номера кузова/шасси нет, платный запрос не предлагается.
Запись привязана к исходному документу, а не к последнему расчёту в диалоге.

Проверка платная по тарифу провайдера, включая отсутствие сведений.
Один Durable Object на идентификатор предотвращает параллельные списания;
готовый ответ используется повторно 24 часа, в том числе после новой загрузки.
Фоновый alarm позволяет дождаться ответа дольше лимита webhook `waitUntil`.
`PROCESSING` повторяется с теми же параметрами только внутри оплаченного
30-минутного окна (наш предел — 25 минут от запуска); сетевой сбой и прерванный
запрос не повторяются автоматически при неизвестном результате списания.
Доступ проверяется при показе кнопки, нажатии, запуске запроса и отправке ответа.

Выводятся все записи ФТС: сверка VIN/кузова/шасси и написания наименования,
дата выпуска, статусы утильсбора, код таможни, личное пользование.
Различие написания требует ручной сверки, а отсутствие сведений не означает
неуплату. Сумма оплаченного утильсбора API не заявлена. Даты/формулы пеней
и обычные расчёты не меняются. VIN в ответах скрыт спойлером.

Проверка без оплаты: тестовый VIN `X7TEST00000000001` из документации AvtoVinCod.
Ответ с `testMode: true` явно помечается как условный тест.
Исходные PDF не сохраняются. Минимальный контекст сверки (идентификаторы
и наименование) хранится отдельно от аналитики; сохраняются последние 30
кнопок пользователя, действуют 30 дней. Результат ФТС используется 24 часа.
